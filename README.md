# douglasgouveia.dev

Personal site of Douglas Gouveia, built with Astro 7 and deployed on Vercel.

```sh
npm install
npm run dev        # http://localhost:3014
npm run check      # astro check
npm test           # vitest
npm run build      # dist/ + .vercel/output
```

The contact endpoint needs `BREVO_API_KEY` in `.env` (see `astro.config.mjs`).
